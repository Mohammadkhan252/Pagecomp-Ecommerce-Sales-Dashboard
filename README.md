# Pagecom E-commerce Sales Dashboard
Power BI e-commerce sales dashboard and data analysis project

## About

This is a Power BI project I created to analyze e-commerce sales data. I created this dashboard to make the sales data easier to understand and to see different sales trends and information.

## Tools Used

* Power BI
* Power Query
* Data Cleaning
* Data Transformation
* Data Visualization

## What I Analyzed

* Sales
* Products
* Customers
* Orders
* Sales trends
* Revenue

## Project Goal

The goal of this project was to practice working with e-commerce data in Power BI and create a simple dashboard that presents the data in a clear way.
